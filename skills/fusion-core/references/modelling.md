# Parametric modelling and focused edits

- Give components, interface parameters and consequential timeline features functional names. Organise features in dependency order. Establish datums and critical interfaces, add base features, then patterns and finishing features. Parameterise dimensions the user will vary and bind the features or sketch constraints to those expressions. Use stable datums for critical dependencies where practical.
- On inspection, identify parametric or direct modelling mode, target geometry, occurrence context, relevant references, timeline warnings and downstream dependencies. If a shared component is instantiated several times, check whether editing its definition would affect multiple occurrences. Inspect before changing, repair the earliest relevant failed dependency, then recompute and recheck downstream geometry. Preserve linked assets and unrelated history.
- For a part, check envelope, hole size and spacing, mounting interfaces, minimum edge distances and tool or fastener access as relevant. Compare against supplied dimensions. If manufacturing constraints depend on a specific process, use confirmed material, stock and tooling, and distinguish nominal CAD dimensions from allowed tolerances. Consider print orientation and weak axes, drill or tool access, bends or cutter radii only where relevant.
- Show parameter editability by perturbing a plausible value, checking the dependent measurement and timeline health, restoring the original expression and checking again. Work on a checkpoint if changing a shared design. Archive or save the native model after checking the intended final configuration.
