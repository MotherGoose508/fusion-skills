# Profile resolution

Use user instructions and confirmed project facts first, then a project override and provided shared defaults. An optional team profile supplies defaults for FRC tasks only. Project overrides take priority over team defaults, which take priority over general defaults. Read only relevant fields. Empty fields leave the prior preference in effect. An explicit project instruction can clear a preference.

Report assumptions that materially affect the build. Confirm a default against the actual machine, stock, hardware, or current project constraints before treating it as a design limit. Leave unknown values unknown. Keep credentials and private access details out of profiles.
